# Introduction to NLP

Text preprocessing and feature extraction pipeline with NLTK, scikit-learn, and gensim on the SMS Spam Collection dataset: exploring the data, cleaning and normalizing messages, tokenizing, removing stopwords, filtering tokens, lemmatizing and stemming, building n-grams, word frequencies and word clouds, and turning text into features with Bag-of-Words, TF-IDF, Word2Vec, and FastText.
