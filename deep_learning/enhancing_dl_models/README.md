# Enhancing Deep Learning Models

Neural network optimization and regularization techniques on the MNIST dataset with Keras: gradient descent variants, momentum-based SGD, adaptive optimizers, learning rate schedules, weight initialization, L2 regularization, dropout, early stopping, and hyperparameter tuning with Keras Tuner.
