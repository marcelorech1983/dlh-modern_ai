# Computer Vision Architectures

CNN architecture pipeline with Keras/TensorFlow on Fashion MNIST: building and training a basic CNN, implementing ResNet bottleneck residual blocks and a full ResNet-101, and implementing MobileNetV1's depthwise separable convolution block, backbone, and full architecture.

## Tasks

|---|---|---|---|
| 0 | Create Convolutional architecture | `0-create_cnn_model.py` | Done |
| 1 | Train CNN | `1-train_cnn.py` | Done |
| 2 | Bottleneck Block | `2-bottleneck_block.py` | Done |
| 3 | ResNet-101 | `3-resnet_101.py` | Done |
| 4 | Depthwise Separable Convolution Block | `4-depthwise_separable_conv.py` | Done |
| 5 | MobileNet Backbone | `5-mobilenet_backbone.py` | Done |

7 of 7 tasks complete.

## Dataset

- `keras.datasets.fashion_mnist` — Fashion MNIST images (28x28 grayscale, 10 classes), used for tasks 0–1
