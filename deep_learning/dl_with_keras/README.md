# Introduction to Deep Learning with Keras

Neural network pipeline on the MNIST dataset with Keras: building shallow and deep classifiers via the Sequential class and the functional API, compiling, training, evaluating, and predicting, saving/loading full models and weights, and logging training metrics to TensorBoard.

## Dataset

- `keras.datasets.mnist` — handwritten digit images (28x28, 10 classes), used across all tasks

## Requirements

- Python 3.11, pycodestyle 2.11.1
- numpy 2.0.2, tensorflow 2.19
- Unless otherwise noted, only `from tensorflow import keras` may be imported
- Every module and function documented
- Files start with `#!/usr/bin/env python3`, end with a newline, and are executable
