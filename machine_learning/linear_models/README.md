# Linear Models

Linear modeling pipeline for regression and classification with Scikit-learn: ordinary least squares, regression evaluation metrics, Ridge (L2) and Lasso (L1) regularization, model explainability with SHAP, logistic regression with decision boundaries, and Support Vector Machines across linear, polynomial, and RBF kernels.

## Datasets

- Synthetic regression data via NumPy (`np.random`) with multicollinear and sparse-coefficient designs — tasks 0–4
- `sklearn.datasets.make_classification` — binary classification for logistic regression (task 5)
- `sklearn.datasets.make_gaussian_quantiles` — 3-class non-linearly separable data for SVM kernels (task 6)
